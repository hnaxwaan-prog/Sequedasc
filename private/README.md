# Private files

The attorney's stamp contains a real signature, so it is **never committed to git**
(this repository is public). `*.png` files in this folder are ignored.

The easiest way to install the stamp is to sign in at `/admin` and use the **Stamp** button.
It is then saved to `DATA_DIR/stamp.png` on the server.

Alternatively, copy the prepared stamp (transparent PNG, 1737 × 1125 px) to `private/stamp.png`
on the server. An uploaded stamp takes priority over this file.
